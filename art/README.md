# Art

| File | What it is | Grid |
| --- | --- | --- |
| `characters/` | Placeholder character layers (from `tools/make_placeholder_art.py`) | 32×48 per layer |
| `palette.png` | Shared 32-color palette for the placeholder art | 8×4 swatches |
| `ui/damage_digits.png` | Pixel digits for floating damage numbers | 5×7 per digit |
| `tiles/textures_02_08_25.png` | Tile textures: stone, brick, wood, water, lava, crystal, plants, fabrics, metal and more | 16×16 tiles, 24 × 26 grid |
| `tiles/textures_16.png` | Tile textures (similar set, grouped by material, with dungeon floor edges at the bottom) | 16×16 tiles, 32 × 32 grid |
| `items/food.png` | 64 food item icons (bread, meat, fruit, drinks, potions and more) | 16×16 icons, 8 × 8 grid |

All sheets use nearest-neighbor filtering (set project-wide), so they stay crisp when scaled.
